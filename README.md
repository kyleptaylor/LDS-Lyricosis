# LDS Lyricosis

Name-that-tune game using real Church hymn recordings. Progressive clips get longer each click — fewer clips heard means more points.

**Play:** [kyleptaylor.github.io/LDS-Lyricosis](https://kyleptaylor.github.io/LDS-Lyricosis/)

## Local / offline

Open `index.html` in a browser. Keep the `audio/` folder next to it.
